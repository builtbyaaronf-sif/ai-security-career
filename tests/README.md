# Testing cadence

| When | Test | Format | Pass |
|---|---|---|---|
| Every Monday | Recall quiz on last week | 15 questions, closed book, ask Claude "run my Monday quiz for week N" | 80% |
| Every Friday | Practical | One task done unaided, timed | Works |
| Every 4 weeks | Mock interview | 45 min: 1 concept round, 1 threat model, 1 code review | Scored rubric |
| End of phase | Gate | See `ROADMAP.md` | 80% |

Missed questions go into `tests/weak-spots.md` and come back in the next 3 quizzes (spaced repetition).
Scores are logged in the weekly log. Two failed gates in a row = slow down, not push on.
