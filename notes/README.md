## Rules
1. **My own words.** No pasted text and no AI written notes. Writing it myself is what makes it stick.
2. **One file per lecture or lab**, named `lecture-00-functions-variables.md`.
3. **End every note with "Questions I still have" and "Quiz me".** These feed the Monday quiz.
4. **No secrets, no spoilers.** For wargames like Bandit, record the concept, never the passwords.
5. **Link notes from the weekly log**, do not copy them into it.
